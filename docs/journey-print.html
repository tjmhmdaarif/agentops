1. What the product is

An autonomous AIOps platform: a simulated IoT fleet streams telemetry; a hybrid anomaly-detection engine finds faults; an autonomous agent investigates, decides, remediates, verifies recovery, and closes or escalates incidents — every step persisted and streamed live to a cinematic dark dashboard wrapped in a WebGL particle-globe landing experience.

SIMULATED FLEET (12 devices × 7 metrics, 12 failure scenarios)
→ HYBRID DETECTION (robust z-score + fast/slow EWMA + rate-of-change + Isolation Forest)
→ INCIDENT MANAGER (persistence · cooldowns · correlated grouping · watchdog)
→ AUTONOMOUS AGENT (investigate → decide → remediate → verify → resolve/escalate)
→ SSE EVENT STREAM → REACT DASHBOARD (live)
→ PARTICLE GLOBE (30k real land points → dissolve → login → deep-space app background)

No LLM key required — deterministic rule engine by default; optional Anthropic mode with validated structured output and automatic rule fallback. Single Docker container serves API + UI. Login-gated. CI-gated. One-click rollback.

2. Architecture

React/Vite (dashboard, lazy three.js chunk)
      │ REST (Pydantic schemas) + SSE (/api/events/stream, cookie-auth)
      ▼
FastAPI ── SimulationEngine (tick-driven, seeded RNG)
       ├─ HybridDetector (zscore/ewma/rate/iforest → fused score)
       ├─ IncidentManager (lifecycle state machine)
       ├─ AgentRuntime (per-incident state machines, 12-tool registry)
       ├─ AuthService (PBKDF2, DB sessions, httpOnly cookies)
       └─ SQLite via repository layer (batch writes, indexed)

Deliberately lightweight: no Kafka, Redis, or Celery. DATABASE_URL can move to PostgreSQL later with zero code changes.

3. Build phases (in order)

  1. Backend core — env config, event bus, logging, SQLAlchemy models + repository, Pydantic schemas.
  2. Simulation — seeded per-device baselines + diurnal drift, 12 failure scenarios, ambient injector, demo script.
  3. Detection — robust z-score, EWMA divergence, gated ROC, per-device Isolation Forests; fusion + suppression.
  4. Incident manager — lifecycle state machine, cross-metric grouping, offline watchdog.
  5. Tools + agent — 12-tool registry (risk classes, idempotency), agent state machine, rule chains, recovery verification, LLM fallback.
  6. API + SSE — full REST surface, simulation control, injection, analytics, one event stream.
  7. Tests — 58 tests including a deterministic end-to-end autonomous-loop test.
  8. Frontend — fleet grid, live charts, incident timeline drawer, analytics, simulation control, settings.
  9. Scenario validation — all 12 failure scenarios verified end-to-end, with and without Isolation Forest.
  10. Auth — PBKDF2 users, DB sessions, cookie middleware, landing/login, change-password.
  11. Cinematic globe — Natural Earth → 30k particles, GPU dissolution, drag physics, starfield/dust/nebula.
  12. Ship — Docker, compose, render.yaml, CI, docs → GitHub → Render production.

8. Disaster recovery — restore on a new machine

# 1. Install: Python 3.12+, Node 20+, git
git clone https://github.com/tjmhmdaarif/agentops.git
cd agentops

# 2. Backend
python -m venv backend/.venv
backend/.venv/Scripts/pip install -r backend/requirements.txt    # Windows
# backend/.venv/bin/pip install -r backend/requirements.txt      # macOS/Linux

# 3. Frontend
cd frontend && npm install && npm run build && cd ..

# 4. Run
./start-backend.ps1
# open http://localhost:8000 — fleet boots; dev login: admin / agentops

# 5. Re-deploy anywhere: repo includes Dockerfile + render.yaml —
#    Render Blueprint or Railway picks them up automatically.
Secrets policy: the production admin password lives only in Render's Environment — never in git. Local dev credentials (admin/agentops) apply only to fresh local databases.

9. Feature flags — the experiment safety valve

FEATURE_FLAGS="predictive_health=true,chaos_controls=false"

Default OFF in main. Flag OFF = the feature 404s and its UI hides. Flip flags in Render → Environment for a sub-minute rollback without redeploying. Reference implementation: the predictive_health flag and its experimental failure-risk card.
